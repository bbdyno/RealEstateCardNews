# 수익화 설계 (광고 · 직접 광고 · 유료 서비스)

2026-09-30 초안. 근거가 된 정책·법령은 맨 아래 출처에 모았다. 금액·요율은 확인한 날 기준이라 시행 전에 다시 본다.

## 0. 전제

- **호스팅은 GitHub Pages(무료).** 사이트는 누구나 보는 정적 페이지로 둔다. GitHub Pages 는 상거래가 주목적인 사이트를 금지하므로
  **결제·계정은 사이트 밖**(결제대행사 결제창 + 작은 서버 함수)에서 처리한다. 광고가 붙은 정보 사이트는 문제없다.
- **공공데이터만 쓴다.** 국토부 실거래가 API 는 이용허락범위 '제한 없음'이라 가공 데이터를 유료로 제공해도 된다(출처 표기).
- **하지 않는 것:** 네이버 매물 수집·가공, 개별 매물 광고(공인중개사법 18조의2), 대출 비교·추천(금융소비자보호법상 미등록 중개 위험).
  중개사 광고를 받으면 18조의3 에 따라 국토부 자료 제출·조치 의무가 생기므로 초기에는 받지 않는다.

## 1. 단계

| 단계 | 시점 | 내용 | 비용·요건 |
|---|---|---|---|
| 0. 품질 기준 | 배포 전 | 얇은 페이지 정리, 분석 도구, 약관·개인정보 보강 | 0원 |
| 1. 네트워크 광고 | 배포 2~4주 뒤 | 애드센스 신청 → 승인 후 게재. 쿠팡 파트너스 블록. 애드핏은 제휴 문의(초대·승인제) | 0원, 개인 가능 |
| 2. 직접 광고 | 인스타 1만 무렵 | 분양 광고·협찬 — 사이트 '스폰서 카드'와 인스타 게시물 | 광고 표시 의무 |
| 3. 유료 '레이더 플러스' | 광고 안정 뒤 | 알림·리포트·엑셀 — 사이트는 그대로 무료, 유료는 '보내 주는' 기능 | 사업자등록 권장 |

## 2. 품질 기준 (애드센스 승인의 핵심)

애드센스 게시자 정책은 가치가 낮은 화면에 광고를 금지하고, 구글 검색 스팸 정책은 순위 조작 목적의 대량 생성 페이지(scaled content abuse)를 금지한다.
6.7만 개 템플릿 페이지가 거절 위험의 가장 큰 요인이다.

| 등급 | 기준(3년 매매+전월세) | 개수(09-30) | 처리 |
|---|---|---|---|
| 풍부 | 20건 이상 | 약 3.2만 | 색인 O · 광고 최대 3개 |
| 보통 | 10~19건 | 약 7,700 | 색인 O · 광고 1개(아래) |
| 얇음 | 10건 미만 | 약 2.3만 | **페이지를 만들지 않는다.** 링크는 시군구 페이지로, 사이트맵에서도 뺀다 |

- 기준 숫자는 `config.yaml` 의 `build.tiers` 로 조정한다.
- 얇은 페이지를 빼면 GitHub Pages 용량(1GB)도 함께 줄어든다(09-30: 단지 페이지 43,841개, 사이트 915MB).
- 모든 단지 페이지에는 그 단지에서만 나오는 계산값(지금 시세·3년 범위 위치·층별·갭·해제 신고가·비슷한 단지)이 들어가 있어야 한다 — v2 디자인이 이 기준을 채운다.
- 분석 도구: 구글 애널리틱스 4(무료). 광고 심사·직접 광고 영업 모두 트래픽 수치가 필요하다.

## 3. 광고 자리 (v2 레이아웃 기준)

**자리 이름과 위치**

| 자리 | 위치 | PC | 모바일 |
|---|---|---|---|
| `top` | 컬러 타일 아래(첫 화면 히어로·탭 옆에는 두지 않는다 — 잘못 누르기 방지) | 728×90 또는 반응형 | 320×100 |
| `mid` | 그래프 카드와 표 사이 | 반응형 | 300×250 |
| `bottom` | 바닥글 위 | 반응형 | 300×250 |
| `list` | 긴 목록(예산별·신고가·랭킹) 10줄마다 한 번, 최대 2개 | 반응형 | 320×100 |
| `coupang` | 맥락이 맞는 페이지에 1개 | 상품 3~4개 | 가로 스크롤 |

- 한 페이지에 네트워크 광고는 **3개까지**(애드핏 규정은 4개까지). 약관·개인정보·404·계산 방법 페이지에는 넣지 않는다.
- 자리마다 높이를 미리 잡아 두어 화면이 밀리지 않게 하고, 광고가 안 채워지면 자리를 접는다.
- 모든 자리 위에 작게 '광고'를 표시한다.

**채우는 순서(자리 하나에 한 광고, 순서대로)**

1. **직접 광고(스폰서)** — 기간·지역이 맞는 계약이 있으면 그것.
2. **애드센스** — 안 채워지면 애드센스가 `data-ad-status="unfilled"` 를 붙인다(최상위 창에서만). 이를 감지해 다음으로 넘긴다.
3. **카카오 애드핏**(승인된 경우) — `data-ad-onfail` 콜백이 오면 자리를 접는다.

애드핏 운영정책은 여러 네트워크 스크립트를 '동시에' 거는 것을 제한하고 순차 사용은 허용하므로, 한 자리에 두 광고를 동시에 띄우지 않는다.

**쿠팡 파트너스**

- 맥락 연결: 전세·전월세가 많은 단지 → 이사·청소 용품, 신축(5년차 이내) → 가전·가구, 재개발·빌라 → 부동산 책, 그 밖 → 부동산 책.
- 블록 **맨 위**에 "이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." (가이드 권장 문구, 반려 사유 1위가 미표시)
- 금지: 접속하자마자 쿠팡으로 넘어가기, 본문을 가리는 떠다니는 배너, "밀어서 확인" 같은 덮개형.
- 누적 판매 15만 원 전에는 수익이 지급되지 않고 Open API 도 못 쓴다 → 처음엔 카테고리·다이내믹 배너 코드로 시작.

**개인정보·동의**

- 개인정보처리방침에 구글·카카오·쿠팡·애널리틱스 쿠키와 끄는 방법을 적는다.
- 유럽(EEA·영국·스위스) 방문자에게는 구글 '개인 정보 보호 및 메시지'(인증 CMP) 동의창을 켠다. 없으면 그 지역은 제한 광고만 나간다.
- `ads.txt` 는 애드센스 줄을 자동으로 쓴다(이미 구현).

## 4. 직접 광고(분양·협찬)

- **스폰서 카드:** v2 컬러 타일과 같은 모양의 카드에 '광고 · 광고주명'을 첫 줄에 표시. `data/sponsors.yaml` 에 기간·지역(시도·시군구)·문구·링크·이미지를 적으면 빌드가 해당 페이지 `top` 자리에 넣는다.
- **분양 광고:** 분양신고번호·분양가 같은 표시 항목은 분양사업자 의무지만, 받을 때 광고안에 들어 있는지 확인한다.
- **인스타 협찬:** 추천·보증 심사지침(2024-12-01 시행)에 따라 '광고'·'협찬'을 캡션 첫 줄과 이미지 첫 장에 표시.
- 광고 소개서(미디어킷)는 인스타 1만·월 방문 수치가 생기면 만든다. `/ads/` 페이지에 문의 메일만 먼저 둔다(이미 있음).

## 5. 유료 '레이더 플러스'

**원칙:** 사이트는 전부 무료·공개로 둔다(검색·애드센스에 유리하고, GitHub Pages 규정과도 맞다).
유료는 **'찾아서 보내 주는' 기능**으로 판다 → 로그인 화면이 필요 없고 정적 사이트를 건드리지 않는다.

| 기능 | 내용 | 무료 체험 |
|---|---|---|
| 관심 단지 알림 | 새 실거래·신고가·해제·신규 전세가 올라오면 다음 날 아침 메일 | 단지 1개 무료(청약철회 제한에 필요한 '미리보기' 역할도 한다) |
| 조건 레이더 | 예산·지역·평형 조건 → 조건에 새로 들어온 거래·단지 주간 리포트 | 첫 주 무료 |
| 하락 거래 레이더 | 최근 3개월 중위보다 10% 넘게 싸게 계약된 거래 알림(실거래 기준이라 매물 자료 없이 가능) | – |
| 엑셀 받기 | 단지·동·시군구 전체 거래 CSV | 표본 1개 |

- **가격(안):** 30일 이용권 4,900원. 아파트썸(9,900원)의 절반으로, 네이버 매물 없이 공공데이터만 쓰는 대신 전국·오피스텔·빌라까지 다룬다.
- **보내는 수단:** 이메일(Brevo 무료 하루 300통, Resend 무료 하루 100통·월 3,000통) → 구독자가 늘면 알림을 하루 한 통으로 묶는다.
  카카오 알림톡(건당 13원 안팎)은 사업자·비즈니스 채널 인증이 필요해 사업자등록 뒤에 붙인다. 텔레그램은 무료 선택지로 둔다.
- **결제:** 정기결제(빌링)는 결제대행사 심사가 따로 있고, 금액을 올릴 때 30일 안에 동의를 받아야 한다 → **처음엔 30일 이용권(한 번 결제)**.
  - 사업자 없이: PayApp 개인(카드 4.0%) — 가능하지만 계속 팔면 사업자 전환이 필요하다고 안내한다.
  - 사업자 있으면: PayApp 사업자(1.9~3.4%), 토스페이먼츠(가입비·연관리비 있음), 포트원(사업자 필수).
  - 간이과세자는 통신판매업 신고가 면제된다(직전 연도 50회 미만도 면제).
- **구조:**
  1. 사이트의 '레이더 플러스' 안내 페이지 → PayApp 결제창(사이트 밖)
  2. 결제 완료 알림(웹훅) → Cloudflare Workers 무료 함수 + D1 무료 DB 에 이메일·만료일 저장
  3. 매일 GitHub Actions 빌드가 끝나면 구독자 목록을 받아 조건에 맞는 거래를 골라 메일 발송
  4. 구독 설정(관심 단지·조건)은 메일 속 링크(서명된 1회용 주소)로 바꾼다 — 비밀번호·로그인 없음
- **표시 의무:** 결제 페이지에 상호·연락처·청약철회 제한 사실(제공 시작 뒤 철회 제한, 무료 체험 제공), 개인정보 수집 항목(이메일·결제 정보는 결제대행사 위탁).

## 6. 설정(구현됨, 09-30)

- `config.yaml` 의 `ads.adsense`(client·slots), `ads.adfit.units`(자리별 id·w·h), `ads.coupang`(enabled·banners: book·move·appliance), `analytics.ga4`.
  비어 있는 값은 그리지 않는다 — 승인 전에는 비워 둔다. `ads.txt` 는 애드센스 client 로 자동 생성.
- 자리: 단지 페이지는 3년 거래 20건 이상(`build.tiers.rich_min`)이면 top+bottom, 그 밖은 bottom 만. 지역·시도는 top+bottom, 홈은 top·mid·bottom.
- 순서: `web/static/app.js` 가 애드센스를 요청하고 `data-ad-status="unfilled"` 면 애드핏(`data-fallback`)으로 바꾸고, 애드핏 `data-ad-onfail` 이면 자리를 접는다.
- 직접 광고: 저장소 루트 `sponsors.yaml`(기간·지역). 시군구·단지·시도 페이지의 top 자리에 '광고 · 광고주' 카드로 들어가고 링크는 `rel="sponsored"`.
- 쿠팡: 단지 페이지는 맥락(5년차 이내 → 가전·살림, 전월세가 매매의 2배 넘으면 → 이사, 그 밖 → 책), 지역·홈은 책. 고지 문구는 블록 맨 위.
- 테스트: `tests/test_build.py` — 광고 ID 가 없으면 광고 표시가 전혀 없음, 애드센스 자리에 애드핏 대체 정보, 직접 광고 기간·지역.
